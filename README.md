# Mentora

Mentora is a learning hub that connects learners with professors and professionals. Learners chat with an AI assistant about what they want to learn, get matched with a suitable expert, book a session, and pay.

**Live app:** https://mentora-hub.ai.studio/

## The Problem

Learners at every level, from undergraduates to PhD students and working professionals, often get stuck and don't know who to ask. Finding the right expert is hard, and generic search doesn't give personal guidance.

## How It Works

1. The learner picks their level and areas of interest.
2. They chat with the AI assistant about their goal.
3. The AI recommends matching experts.
4. The learner books a session and pays.
5. The expert delivers the session.

## Features

- Onboarding by learning level and interests
- AI chat powered by the Gemini API
- Expert matching and expert profiles
- Session booking (date, time slot, session type)
- Simulated payment flow with confirmation
- My Sessions page for upcoming sessions

## Built With

- Google Stitch (UI/UX design)
- Google AI Studio (app build)
- Gemini API
